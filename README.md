## 仓库结构

```
.
├── index.html                      # 网页（GitHub Pages 入口，勿直接编辑）
├── source/
│   ├── hangzhou-3day-guide.html    # 源文件（改这个，然后跑同步脚本）
│   └── deploy_site.py              # 可选：部署到自有服务器的 SSH 脚本
├── sync-to-github.ps1              # 一键同步脚本
├── README.md
└── .nojekyll
```

`index.html` 是 `source/hangzhou-3day-guide.html` 的副本。单一真源在 `source/`，同步脚本会自动复制，不需要手动改两处。

## 更新后如何同步

在本地改完 `source/hangzhou-3day-guide.html`，然后：

```powershell
.\sync-to-github.ps1
```

脚本会：复制源文件到 `index.html` → 提交 → 推送。推送成功后 Pages 约 1 分钟自动更新。

也可以带自定义提交信息：

```powershell
.\sync-to-github.ps1 -Message "调整周六晚间演出顺序"
```

## 技术说明

- **零依赖单文件**：HTML + CSS + 内联 JS，不引用任何外部 CSS/JS 文件（腾讯地图 SDK 按需动态加载）
- **地图三层降级**：腾讯地图 JSAPI GL → Leaflet → 内联静态 SVG。Key 的域名白名单不含 GitHub Pages 时会自动降到第二层，行程文字与卡片不受影响
- **数据驱动渲染**：行程数据集中在 `const dayData = [...]` 与 `const HOTEL_CANDIDATES`，改数据即可，不用动模板
- **移动端适配**：竖屏排版，行程卡片单列，适合旅途中手机查看
